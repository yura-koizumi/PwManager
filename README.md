# PwManager 運用ガイド

Windows 10/11 の標準機能（Windows PowerShell 5.1 と Windows Forms）と、Microsoft 製の
`Microsoft.PowerShell.SecretManagement` / `Microsoft.PowerShell.SecretStore` だけで動くパスワード管理ツールです。
クラウドに送信せず、費用もかかりません。

---

## 1. セットアップ（初回・アップデート共通）

1. このフォルダー（`PwManager`）を PC の任意の場所に置きます。アンインストールにも使うので、消さずに残しておくか、ダウンロードした ZIP を取っておいてください。
2. フォルダー内の `Install.bat` をダブルクリックします。

   PowerShell から実行する場合は、フォルダー内で Shift + 右クリック →「PowerShell ウィンドウをここで開く」を選び、次を実行します。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
   ```

3. 初回だけ、マスターパスワードの設定を求められます。
   - 12 文字以上で、ほかでは使っていないもの（長めのフレーズがおすすめ）
4. 続けて **回復キー**（`XXXX-XXXX-…` の 32 文字）が表示され、デスクトップに `PwManager-回復キー-….txt` として保存されます（デスクトップが OneDrive などで同期されているときは、クラウドに上がらないよう、同期されない「ダウンロード」フォルダーに保存します。保存先は画面に表示されます）。印刷するか USB メモリーなどに移して、**ファイルは PC から削除してください**（PC に残すと、保管庫と一緒に持ち出されたときに開かれてしまいます）。バックアップの ZIP とも別の場所に保管します。
   - バックアップから戻すとき（新しい PC への移行など）と、マスターパスワードを忘れたときに使います。
   - 回復キーをなくしても、この PC ではマスターパスワードでそのまま使えます。
5. デスクトップとスタートメニューに「PwManager」ができます。

プログラムは `%LOCALAPPDATA%\Programs\PwManager` に入ります（使う SecretManagement / SecretStore も一緒にここへ入れます）。PowerShell で `pwm` などのコマンドを使えるよう、ユーザーの環境変数 `PSModulePath` にこの場所を足します（アンインストールで元に戻します）。最初の導入時だけ、PowerShell Gallery（インターネット）からそのモジュールをダウンロードします。それ以降の利用はすべて PC の中で完結します。

> **アップデートするとき**：新しい `PwManager` フォルダーで同じ `Install.bat`（または `Install.ps1`）を実行します。設定と保管庫のデータは別の場所にあるため、そのまま残ります。版ごとの変更点は [CHANGELOG.md](CHANGELOG.md) にあります（今の版は画面のタイトルに出ます）。

## 2. 毎日の使い方

デスクトップの「PwManager」を起動し、マスターパスワードを入力します。画面のボタンは「＋ 新規」と「≡（メニュー）」だけで、行ごとの操作はキーボード・ダブルクリック・右クリックで行います。

| やりたいこと | 操作 |
| --- | --- |
| 探す | 上の検索欄に入力します（スペースで区切ると AND 検索。大文字小文字・全角半角・ひらがなカタカナは区別しません） |
| 並べ替える | 列の見出しをクリック（もう一度クリックすると逆順） |
| **パスワードをコピー** | 行を選んで **Enter**。検索欄で Enter を押すと、選ばれている行（検索した直後は先頭の行）のパスワードをコピーします |
| ID / URL をコピー | その列をダブルクリック、**Ctrl+C**（選んでいるセルの列）、または右クリック |
| URL をブラウザーで開く | 右クリック →「URLを開く」 |
| 新規登録 | 「＋ 新規」または **Ctrl+N**。「生成」を押すと強いパスワードを自動で作ります（その下で長さと「英数字と記号・英数字のみ・数字のみ」を選べます。サイトの決まりに合わせるときに） |
| 変更前のパスワードを使う | 右クリック →「変更前のパスワードをコピー」。パスワードを変えると、1 つ前のものだけを残します（新しいパスワードが相手のサイトで通らなかったときなどに） |
| 編集 | **F2**、タイトルをダブルクリック、または右クリック。パスワード欄を空欄のままにすると、パスワードは変わりません |
| 複製 | **Ctrl+D** または右クリック →「複製...」。ID・URL などを入れた新規登録が開きます（パスワードは使い回さないよう引き継ぎません。「生成」で作れます） |
| 削除 | **Del**、または右クリック（確認画面が出ます） |
| 席を離れる | **Ctrl+L** でロック（10 分間操作がないと自動でロック） |
| そのほか | **≡** から、バックアップ・CSV の取り込みと書き出し・マスターパスワードの変更・設定ファイルを開く・ロック |

**コピーしたパスワードの扱い**

- コピーしたパスワードは 30 秒後に自動で消えます。ただし、その間に別の物をコピーした場合は、そちらを消さないようにしています。
- Windows のクリップボード履歴（Win+V）やクラウド同期には残りません。

## 3. 設定のカスタマイズ

設定ファイルは `%APPDATA%\PwManager\config.json` です。画面の **≡** →「設定ファイルを開く」で開き、保存したあと PwManager を開き直すと反映されます（メモ帳が無ければ、.json に関連付けられたアプリ、それも無ければエクスプローラーでファイルの場所を開きます）。
書かなかった項目には既定値が使われるので、変えたい項目だけを書けば十分です（`PasswordGenerator` の中も、書いた項目だけが変わります。`Fields` と `Categories` は、書いた一覧で置き換わります）。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| `ClipboardClearSeconds` | 30 | コピーしたパスワードを消すまでの秒数（0 にすると消さない） |
| `ExcludeFromClipboardHistory` | true | パスワードをクリップボード履歴やクラウド同期の対象から外す |
| `AutoLockMinutes` | 10 | 何分間操作がなければロックするか（0 にすると自動ロックしない） |
| `UnlockTimeoutSeconds` | 900 | 一度ロックを解除したあと、保管庫を開いたままにする秒数（過ぎると、使っている途中でもマスターパスワードの再入力を求める）。短いほど安全で、再入力は増える。120 以上 |
| `Fields` | ID, URL, 備考 | 表示・入力する項目（下で詳しく説明） |
| `Categories` | （なし） | カテゴリの候補（`Type: "Category"` の項目を作ったときだけ使う） |
| `PasswordGenerator` | 20 文字・記号あり | 「生成」の既定の長さ（`Length`、4〜128）、記号を使うか（`Symbols`）、使う記号（`SymbolChars`） |
| `VaultName` | PwVault | SecretManagement に登録する保管庫の名前（ふつうは変えない） |

### 項目（Fields）を追加・変更する

例：「メール」と「社員番号」の項目を追加し、どちらもコピーできるようにする場合

```json
"Fields": [
  { "Name": "Id",    "Label": "ID",       "Copy": true },
  { "Name": "Email", "Label": "メール",   "Copy": true },
  { "Name": "EmpNo", "Label": "社員番号", "Copy": true },
  { "Name": "Url",   "Label": "URL",      "Copy": true, "Open": true },
  { "Name": "Note",  "Label": "備考",     "Multiline": true }
]
```

| キー | 意味 |
| --- | --- |
| `Name` | 保存に使う名前（英数字）。**一度使い始めたら変えないでください**（変えると、それまでに入れた値が表示されなくなります） |
| `Label` | 画面に表示する名前。いつでも自由に変えられます |
| `Copy` | 右クリックメニューに「〇〇をコピー」を出す |
| `Open` | 右クリックメニューに「〇〇を開く」を出す（http:// または https:// で始まる値だけ開きます） |
| `Sensitive` | コピーした値をパスワードと同じように扱う（一定時間で消し、履歴にも残さない） |
| `Type: "Category"` | 分類用の項目にする。検索欄の横に、その値で絞り込むリストが出る（例：`{ "Name": "Category", "Label": "分類", "Type": "Category" }`） |
| `Multiline` | 複数行で入力できるようにする |

項目を `Fields` から削除しても、保存済みのデータは消えません。あとで戻せば、また表示されます。

## 4. バックアップ・復元・PC の移行・アンインストール

### バックアップ（移行するとき）

新しい PC への移行や、万一に備えたいときに、手で取ります（自動では取りません）。画面の ≡ →「バックアップ」で保存先のフォルダーを選ぶか、PowerShell で次を実行します。

```powershell
Backup-PwVault -Destination E:\Backup
```

ZIP の中の保管庫データは暗号化されたままで、戻すには **回復キー** が必要です（マスターパスワードでは開きません）。回復キーは ZIP と同じ場所に置かないでください。古いバックアップは自動では消さないので、不要になったら手で削除してください。

### 復元・新しい PC への移行

1. （新しい PC の場合）このフォルダーをコピーして `Install.bat` を実行します。マスターパスワードを求められたら、仮のものを入力して構いません（復元すると置き換わります）。
2. PwManager の画面を閉じ、**新しく開いた** PowerShell で次を実行します（画面が開いていると、復元は止まります）。

   ```powershell
   Restore-PwVault -Path D:\Backup\PwManager\PwManager-backup-PC01-20261118-090000.zip -IncludeConfig
   ```

   回復キーを入力し、続けてこの PC で使うマスターパスワードを設定します（以前と同じでも構いません）。回復キーが違うときは、何も変えずに止まります。
3. PwManager を起動し、いま設定したマスターパスワードで開きます。回復キーは以前と同じものを引き続き使います。

復元する前の保管庫は `%APPDATA%\PwManager\pre-restore-*.zip` に自動で退避されます（それまでの回復キーで戻せます）。

> **年に 1 回は、別の PC か別のユーザーで復元を試してください。** バックアップは「元に戻せること」を確かめて初めて役に立ちます。

### マスターパスワードを変更する

画面の ≡ →「マスターパスワードの変更」を開き、今のパスワードと新しいパスワード（2 回）を入力します。PowerShell で `Set-PwMasterPassword` を実行しても変更できます（その場合は PwManager の画面を閉じておきます）。

- 保存済みのデータもバックアップも、そのまま使えます（バックアップは回復キーで開くため）。
- **マスターパスワードを忘れたとき**は、PowerShell で `Set-PwMasterPassword -UseRecoveryKey` を実行し、回復キーを入力して新しいマスターパスワードを設定します。

### 回復キーを作り直す

回復キーが漏れた心配があるときは、PwManager の画面を閉じて、PowerShell で `New-PwRecoveryKey` を実行します。保管庫を新しい鍵で暗号化し直し、新しい回復キーを表示します。それまでのバックアップは古い回復キーで開けるので、削除して取り直してください。

### アンインストール

フォルダー内の `Uninstall.bat` をダブルクリックします（PowerShell から実行する場合は `powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1`）。PwManager の画面は閉じておきます。フォルダーを消してしまったときは、リリースの ZIP をもう一度展開して実行します。

- プログラムと、デスクトップ・スタートメニューのショートカットを削除します。
- 保管庫のデータと設定は、**既定では残します**。あとで `Install.bat` を実行すれば、そのまま使えます。
- データも削除するときは、途中の質問で `y` を選び、最後に `DELETE` と入力します。保管庫に PwManager 以外のシークレットがある場合などは、削除する前に警告します。手で取ったバックアップ（ZIP）は削除しません。データを残してアンインストールしたあとでも、もう一度 `Uninstall.bat` を実行すればデータを削除できます。
- 一緒に入れた SecretManagement / SecretStore（`%LOCALAPPDATA%\Programs\PwManager`）も削除します。ほかの場所に入っているものと、実行ポリシーは変更しません（実行ポリシーの戻し方は最後に表示されます）。

## 5. ほかのツールからの移行・ほかのツールへの移行

### ブラウザー・ほかのパスワード管理ツールから取り込む

Chrome・Edge・Firefox・Bitwarden・1Password・KeePass が書き出す CSV は、そのまま取り込めます（列名から自動で判別します）。

1. 元のツールで、パスワードを CSV に書き出します（Chrome なら 設定 →「Google パスワード マネージャー」→ 設定 →「パスワードをエクスポート」）。
2. PwManager の画面の **≡ →「CSV から取り込む...」** で、書き出した CSV を選びます。PowerShell からなら、画面を閉じてから次を実行します。

   ```powershell
   Import-PwCsv -Path 'C:\Users\<ユーザー名>\Downloads\Chrome パスワード.csv'
   ```

3. **取り込みが済んだら、CSV を削除し、ごみ箱も空にしてください。** 元のツールに残っているパスワードも、必要なければ削除します。

- Firefox の CSV にはタイトルが無いので、URL のドメイン名（`example.com` など）をタイトルにします。
- パスワードが空の行（Bitwarden のメモなど）は取り込みません。
- 2 段階認証の鍵（`login_totp`・`OTPAuth`）やタグなど、入れる先の無い列に値が入っていると、取りこぼさないよう止まります（列があっても空なら止まりません）。要らなければ `-IgnoreUnknownColumns` を付けて実行します。

### Excel から取り込む

1. Excel の 1 行目（見出し）を `Title`, `Password`, `Id`, `Url`, `Note` にします（`Fields` に追加した項目も使えます）。日本語の見出し（タイトル、パスワード、および `Fields` の `Label`）でも構いません。
2. 「名前を付けて保存」で **CSV UTF-8** か **CSV (コンマ区切り)** を選んで保存します（文字コードは自動で判別します）。
3. 画面の **≡ →「CSV から取り込む...」** で選ぶか、PowerShell で次を実行します。

   ```powershell
   Import-PwCsv -Path 'C:\work\passwords.csv'
   ```

4. **取り込みが済んだら、CSV と元の Excel ファイルを削除し、ごみ箱も空にしてください。**

取り込み先の項目が無い列（たとえば「メール」）があると、データを取りこぼさないよう、取り込まずに止まります。その列も残したいときは `Fields` に項目を追加してから（[項目を追加・変更する](#項目fieldsを追加変更する)）、要らないときは `-IgnoreUnknownColumns` を付けて実行します。

同じ CSV を 2 回取り込むと、エントリが重複します。

### 書き出す

画面では **≡ →「CSV に書き出す...」** を選び、保存の画面の「ファイルの種類」で「ブラウザー・ほかのツール向け」「Excel 向け・パスワードあり」「Excel 向け・パスワードなし」から選びます。コマンドでは次のとおりです。

| 書き出し方 | 用途 |
| --- | --- |
| `Export-PwCsv -Path 'chrome.csv' -Format Chrome` | ブラウザー（Chrome・Edge・Firefox）や、Bitwarden・1Password などに取り込む。パスワードを必ず含みます |
| `Export-PwCsv -Path 'out.csv' -IncludePassword` | Excel で開く・保管する。`-IncludePassword` を付けないと、パスワードを含めません |

- どちらも、パスワードを含めるときは確認画面が出ます。**使い終わったら CSV を削除し、ごみ箱も空にしてください。**
- 既定の形では、Excel で開いたときに数式として実行されないよう、`=` `+` `-` `@` で始まるタイトルや項目の値に `'` を付けます（`Import-PwCsv` で取り込むと元に戻ります）。
- Chrome 形式では、取り込む側に `'` が残らないよう、値をそのまま書きます。Excel では開かないでください。

## 6. PowerShell から使う

`Get-PwHelp` でコマンドの一覧を、`Get-PwHelp <コマンド>` で引数の説明と例を表示します。

| コマンド | 内容 |
| --- | --- |
| `pwm` | 画面を開く |
| `Get-PwEntry 'ポータル'` | 検索する（1 件 1 行の表。パスワードは表示しない） |
| `Copy-PwField 'ポータル'` | パスワードをコピーする（`Copy-PwField 'ポータル' Id` で ID、`-Previous` で変更前のパスワード） |
| `New-PwEntry 'Amazon' -Fields @{ ID = 'taro'; URL = 'https://…' } -Generate` | 登録する（`-Generate` でパスワードを生成。付けなければ入力を求める） |
| `Set-PwEntry 'Amazon' -Fields @{ URL = 'https://…' }` | 指定した項目だけ変える（`-Title` でタイトル、`-Generate` / `-PromptPassword` でパスワード） |
| `Remove-PwEntry 'Amazon'` | 削除する（確認あり） |
| `New-PwPassword -Length 24` | パスワードを生成する（`-NoSymbols` で英数字のみ、`-DigitsOnly` で数字のみ、`-SymbolChars '!@#'` で使う記号を指定） |
| `Edit-PwConfig` | 設定ファイルを開く |
| `Backup-PwVault` / `Restore-PwVault` | バックアップ・復元 |
| `Import-PwCsv` / `Export-PwCsv` | CSV の取り込み・書き出し（ブラウザーやほかのツールの CSV も。`-Format Chrome` でブラウザー向けに書き出す） |
| `Set-PwMasterPassword` | マスターパスワードを変更する（`-UseRecoveryKey` で、忘れたときに回復キーで変更） |
| `New-PwRecoveryKey` | 保管庫の鍵と回復キーを作り直す |
| `Get-PwHelp` | コマンドの一覧 |

### 検索と件数

```powershell
Get-PwEntry '社内 ポータル'          # 空白で区切ると、すべての語を含むもの
Get-PwEntry 'url:example id:taro'   # 「項目:文字」で、その項目だけを探す（項目名は ID・URL・title など）
Get-PwEntry                         # 既定では 50 件まで。残りがあれば件数を知らせる
Get-PwEntry -All                    # 全件
Get-PwEntry -Skip 50 -First 50      # 51〜100 件目
```

結果はふつうの PowerShell のオブジェクトなので、並べ替えや細かい絞り込みは標準のコマンドでできます。

```powershell
Get-PwEntry -All | Sort-Object Updated -Descending | Select-Object -First 10   # 最近更新した 10 件
Get-PwEntry 'ポータル' | Format-List *                                       # 全項目を表示
Get-PwEntry -All | Out-GridView                                              # 表の画面で見る
```

### 注意

- 検索語やタイトルは `'...'`（シングルクォート）で囲みます。空白や記号（`$` `&` `;` など）を含むと、PowerShell が別の意味に読むためです。`"..."` の中では `$` が変数として展開されるので、`'...'` を使ってください（英数字だけなら囲わなくても構いません）。
- パスワードは引数に平文で書かず、`-Generate` で生成するか、入力欄に入力します（コマンドの履歴に残さないため）。
- `Get-PwEntry '旧' | Remove-PwEntry` のように、検索結果をパイプで渡すこともできます。`Copy-PwField` などに検索語を渡して複数のエントリが当てはまるときは、選ぶ画面が出ます（件数は区切りません）。
- 保管庫に書き込むコマンド（登録・編集・削除・CSV の取り込み・マスターパスワードの変更）は、PwManager の画面を閉じてから実行します。
- 保管庫がロックされているときは、マスターパスワードを尋ねます（3 回まで）。

## 7. セキュリティ上の注意

- パスワードは SecretStore によって、ランダムな鍵（保管庫キー）で暗号化して保存されます。保管庫キーは次の 2 通りで包んで保存します。
  - **この PC 用**：マスターパスワードで包み、さらに Windows のユーザーに結び付けて（DPAPI）包みます（`%APPDATA%\PwManager\vaultkey.json`）。保管庫のファイルを持ち出されても、別の PC・別のユーザーでは総当たりを始められません（オフライン攻撃への対策）。
  - **回復用**：回復キー（ランダムな 160 ビット）で包みます。バックアップの ZIP にはこちらだけを入れるので、マスターパスワードの強さに関係なく、総当たりでは破れません。
- それでも、ログオン中の PC でマルウェアが動いている場合は守れません。マスターパスワードは長めのフレーズ（たとえば 4〜5 語をつなげたもの）にしてください。
- 画面でのマスターパスワードの入力に続けて失敗すると、5 回目から次に試せるまでの待ち時間が延びます（5 秒から倍々に、最長 5 分）。次に正しく開いたとき、それまでに失敗した回数と日時を表示します。心当たりがなければ、マスターパスワードを変更してください。
- **秘密にすべき内容はパスワード欄に入れてください。** SecretManagement の仕様上、ID・URL・備考などのメタデータは、機密情報を入れることを前提にしていません。PIN や秘密の質問の答えなどは、備考に書かずに別のエントリとして登録してください。
- 追加・更新・削除・バックアップ・ロック解除の失敗の記録が `%APPDATA%\PwManager\audit.log` に残ります。ログは暗号化されないため、パスワードもタイトル（サービス名）も書かず、エントリの ID（`pwm:…`）だけを記録します。1 MB（約 1 万件）を超えると `audit.old.log` に移し、その 1 つ前の記録は消えます。
- 画面のロック（Ctrl+L・自動ロック）では、PwManager のプロセスを終了して、新しいプロセスでロック解除の画面を出し直します。保管庫の鍵やコピーしたパスワードはメモリーに残りません（コピー中のパスワードはクリップボードからも消します）。`pwm` で開いた場合は、画面を閉じるだけです。席を離れるときは Windows のロック（**Win+L**）も併用してください。
- プログラムは、OneDrive などで同期されない `%LOCALAPPDATA%\Programs\PwManager` に置きます（Documents の下だと、同期先でプログラムを書き換えられたときに、マスターパスワードを盗まれうるため）。使う SecretManagement / SecretStore も同じ場所のものを使います。
- 会社などで PowerShell のログ（モジュールのログ・イベント ID 4103）が有効でも、パスワードと回復キーは残りません。コマンドの引数の値は記録されるので、内部ではパスワードを暗号化した形（SecureString）で受け渡し、クリップボード・ファイルに渡す直前にだけ元に戻しています。ただし、画面に表示したもの（`New-PwPassword` で表示したパスワードや、セットアップで表示した回復キー）は、表示する処理そのものや、画面を記録する仕組み（トランスクリプト）のログに残りえます。ログが有効な PC では、パスワードは画面の「生成」で作るか、`New-PwEntry -Generate` を使ってください（表示せずに登録します）。
- ノート PC の紛失・盗難に備えて、BitLocker（ドライブの暗号化）を有効にしておくことをおすすめします。
- 会社の規程で、業務用パスワードの保管方法が定められている場合は、それに従ってください。

## 8. 困ったときは

| 症状 | 対処 |
| --- | --- |
| ショートカットから起動しない | PowerShell で `pwm` を実行すると、エラーの内容が表示されます |
| 「設定ファイルの書式が正しくありません」と表示される | `config.json` の `,` や `"` の過不足を確認します。分からなくなったら、ファイルを削除すれば既定値に戻ります |
| マスターパスワードを忘れた | `Set-PwMasterPassword -UseRecoveryKey` で、回復キーを使って新しいマスターパスワードを設定します |
| 「この Windows ユーザーでは保管庫を開けません」と表示される | 保管庫は作った Windows ユーザーに結び付いています（別の PC にコピーした、Windows のパスワードを管理者がリセットした、など）。バックアップと回復キーで復元してください |
| バックアップを戻せない | 戻すには、バックアップを取ったときの回復キーが必要です（`New-PwRecoveryKey` で作り直す前のバックアップは、古い回復キーで戻します） |
| 「スクリプトの実行が無効」と表示される | 会社のポリシーで制限されている可能性があります。情報システム担当に相談してください |
| 文字化けする | `.ps1` や `.psm1` を編集したときは、**UTF-8（BOM 付き）** で保存してください |

## 9. ファイルの構成（保守する人向け）

```text
PwManager\                 … 配布用フォルダー
  Install.bat / Install.ps1      … セットアップ・アップデート
  Uninstall.bat / Uninstall.ps1  … アンインストール（既定ではデータを残す）
  README.md / CHANGELOG.md（変更履歴） / LICENSE
  tests\                   … 自動テスト（配布・インストールの対象外）
  tools\Build-Release.ps1  … リリース用フォルダー（release\、git の管理対象外）を作る（-Bump で版を上げる、-IncludeTests でテストも入れる）
  PwManager\               … 本体（%LOCALAPPDATA%\Programs\PwManager\Modules\PwManager にコピーされる）
    PwManager.psd1         … バージョン情報（Build-Release.ps1 -Bump で上げる）
    PwManager.psm1         … 共通の定数と、下の各ファイルの読み込み
    Config.ps1             … 設定・状態・監査ログ
    Key.ps1                … 保管庫キー（マスターパスワード・Windows ユーザーへの結び付け・回復キー）
    Vault.ps1              … 保管庫の操作（登録・更新・削除・一覧・ロック解除・マスターパスワードの変更）
    Clipboard.ps1          … クリップボード（コピー・自動消去）
    Password.ps1           … パスワード生成
    Backup.ps1             … バックアップ・復元
    Csv.ps1                … CSV の取り込み・書き出し
    Setup.ps1              … 初期設定とショートカット
    List.ps1               … 一覧のデータ（表の作成・検索条件・1 行単位の更新）。画面に依存せず、tests\List.Tests.ps1 で検証
    Cli.ps1                … 登録・編集・削除のコマンド（New-PwEntry / Set-PwEntry / Remove-PwEntry）
    Help.ps1               … コマンドの一覧（Get-PwHelp）。コマンドを足したら、ここの分類にも追加する
    Gui.Dialogs.ps1        … 画面の共通部品とダイアログ（ロック解除・登録/編集）
    Gui.List.ps1           … 一覧の画面側（List.ps1 のデータをグリッド・検索欄に結び付ける）
    Gui.Actions.ps1        … 画面の操作（コピー・登録・編集・削除・バックアップ・ロック）
    Gui.Main.ps1           … メイン画面と、画面の状態（$ui）の定義 New-PwUiState。$ui に項目を足すときはここに追加する
    Launch.ps1             … ショートカットから呼び出される起動スクリプト
    config.default.json    … 設定の既定値

%APPDATA%\PwManager\       … config.json / vaultkey.json（保管庫キー） / audit.log / audit.old.log / unlock.json（入力の失敗の記録） / pre-restore-*.zip・pre-rekey-*.zip（復元・回復キーの作り直しの前に退避したもの）
%LOCALAPPDATA%\Microsoft\PowerShell\secretmanagement\localstore\  … 暗号化された保管庫（SecretStore が管理）
```

### 修正するときの手順

1. 修正したら、テストを実行します（追加のモジュールは不要で、実際の保管庫やデータには触れません）。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
   ```

   クリップボードのテストは、実行中にクリップボードを書き換えます（終わると元のテキストに戻します）。

   画面の動作や軽さは、模擬データで確かめられます（実際の保管庫には触れません。マスターパスワードは `demo-password-1`）。

   ```powershell
   powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\Demo-Gui.ps1 -Count 3000
   ```

2. 利用者に見える変更は、`CHANGELOG.md` の「次の版」に 1 行ずつ書き、git にコミットします。
3. リリース用のフォルダーを作ります（テストを実行し、成功したときだけ作ります）。`-Bump` を付けると、版の最後の番号を 1 つ上げ（`0.5.1` → `0.5.2`）、「次の版」をその版の見出しに移します。途中で失敗したら、版と CHANGELOG は元に戻ります。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Release.ps1 -Bump
   ```

   `release\PwManager-<バージョン>\` と、その ZIP ができます。利用者にはこれを渡します（テストや git の情報は含まれません）。配布するファイルを増やしたときは、`Build-Release.ps1` の一覧にも追加します。
4. 配る前に、Windows Sandbox で確かめます。`release\PwManager-Sandbox.wsb` をダブルクリックすると、リリースフォルダーがデスクトップの `PwManager` に読み取り専用で割り当てられた Sandbox が開くので、そこで `Install.bat` を実行します。Sandbox でテストやデモ（`tests\Demo-Gui.ps1`）も動かしたいときは、`-IncludeTests` を付けて作ります。
5. 利用者は、新しいフォルダーで `Install.bat` を実行すれば更新されます。

SecretManagement / SecretStore は、`Install.ps1` でメジャーバージョン 1 系に固定しています。2.0 以降が出たら、テストと実際の画面で動作を確かめてから、`Install.ps1` の `-MaximumVersion` を上げてください。

**保存形式（スキーマ v1）**

- シークレットの名前は `pwm:<GUID>` です。こうしておくと、タイトルを変えてもデータは同じまま残り、同じサービスで複数のアカウントを登録することもできます。
- シークレットの本体はパスワード（SecureString）です。
- メタデータには、`Title`、`Created`、`Updated`、`Schema`、そして `Fields` で定義した各項目が入ります。
- 名前が `pwm:` で始まらないシークレットは、このツールでは表示しません。ほかの用途のシークレットと同じ保管庫に共存できます。
